      4. Git (and create a new GitHub project)
      5. Ollama

  2. Python Virtual Environment

    Note that we build a new virtual environment for this project (and install the Python packages there).

      s
    1. Create Virtual Environment
      1. Inside VSCode, with your project open, open "View -> Terminal" (it will open at your project location)
      2. Type: python -m venv .venv
        (.venv folder is created inside the project folder)
      3. Type: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
      4. Type: .\.venv\Scripts\Activate.ps1
        now you can see in the terminal that the line starts with green (.venv)

  3. Python Packages

    1. Install Python packages

      Open Terminal inside VSCode (with the green .venv).

      1. Type: pip install ollama
      2. Type: pip install numpy
      3. Type: pip install mujoco
      4. Type: pip install opencv-python
      5. Type: pip install ultralytics
        6. pip install customtkinter pip install matplotlib pip install xlwings (temporary)
      6. Open Terminal in the location of your project,
        make sure you are in green (.venv) or activate it,
        then type: pip freeze > requirements.txt
        do it every time you add a new package to your project (will be helpful on moving to other computers).

      7. VSCode looks for the packages in the usual place and mark them as problems.
        Search (Ctrl+Shift+P) for "Python: Select Interpreter",
        choose the .venv one.

Pan Tilt

  1. Hardware

    Pan and tilt of 2 x STS3215, UART2, Lipo 2S C35 2200mAh battery, XT60 wires, ToolkitRC M4 Pocket.

    1. Preparation
      1. Leave only one servo connected, for now

  2. ID Configuration

    FEETECH FD software: FD1.9.8.3

    1. Setup and Change ID
      1. Choose COM3 (check the device manager)
      2. Baud rate 1000000
      3. Click "Open" it turns to "Close"
      4. Click "Search"
      5. Choose the servo
      6. Click "Programming", then "ID", change it to "2"
      7. Now connect the other servo instead, to see that it is ID 1
      8. Connect both, Search, both should appear as ID 1 and ID 2

  3. Testing

    1. Movement Check
      1. Select one ofthe servos
      2. Click Debug
      3. Torque checkbox is checked
      4. Move the slider

  4. Python Packages

    1. Install Python packages

      Open Terminal inside VSCode (with the green .venv).

      1. Type: pip install pyserial
